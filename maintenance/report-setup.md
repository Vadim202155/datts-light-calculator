# Ежедневный отчёт DATTS

Сбор статистики на сайте включён. Для записи в Google Таблицу нужен один запуск Apps Script от владельца Google-аккаунта. После установки отчёт работает на серверах Google, без открытого браузера, компьютера или Codex.

1. Войдите в Google как `jfdjbdy.com@gmail.com` и откройте https://script.google.com/home/start . Создайте проект «DATTS — ежедневный отчёт».
2. Замените содержимое `Код.gs` кодом из `DATTS_daily_report.gs` рядом с этим файлом.
3. В настройках проекта включите показ файла манифеста `appsscript.json`. Замените его содержимым приложенного `appsscript.json`.
4. Сохраните. Выберите функцию `installDattsReport` и нажмите «Выполнить». Подтвердите запрошенный Google доступ к таблицам и ежедневному заданию.
5. В разделе триггеров должна появиться функция `updateDattsReport` с ежедневным запуском. Повторный запуск установки не добавляет второй триггер.

Таблица: https://docs.google.com/spreadsheets/d/1cYKIZSI-NpPPB-j4SXzx3yfqLyblz2lJl6XqV3erlmE/edit

Отчёт обновляется ежедневно между 09:00 и 10:00 МСК за предыдущие сутки; Google выбирает минуту запуска. Строки последних семи дней повторно сверяются и обновляются по дате. Нулевые дни учитываются с 19.11.2026; прежняя история недоступна. Сегодняшняя дата появится после закрытия суток.

В первые девять столбцов входят дневные уникальные браузеры, совершившие действие; в столбцы «Клики» — общее число событий. Открытие письма не подтверждает его отправку, а запуск печати — сохранение PDF. Телефоны и содержимое заявок в статистику не попадают. Анонимные события хранятся 90 дней, дневные сводки сохраняются отдельно.

Публичное развёртывание Apps Script не требуется. Ключи и пароли вводить не нужно: доступ к отчёту проверяется по Google-аккаунту владельца.
